## Описание программы
**Training Planner** - это GUI приложение для планирования тренировок с графическим интерфейсом на Python.  
Позволяет добавлять тренировки, фильтровать по типу и дате, сохранять данные в JSON.

### Возможности:
-✅ Добавление тренировки – кнопка «➕ Добавить тренировку»
-✅ Поля ввода: Дата, Тип тренировки (выпадающий список), Длительность
-✅ Автоматическая нумерация – каждая тренировка получает уникальный ID
-✅ Фильтр по типу тренировки – выпадающий список (Все, Бег, Велосипед, Плавание, Силовая, Йога)
-✅ Фильтр по дате – поле ввода даты (формат ГГГГ-ММ-ДД)
-✅ Кнопка «🔍 Применить фильтр» – применяет оба фильтра одновременно
-✅ Кнопка «❌ Сбросить фильтр» – очищает фильтры и показывает все записи
-✅ Автосохранение – после добавления каждой тренировки
-✅ Ручное сохранение – кнопка «💾 Сохранить в JSON»
-✅ Автозагрузка – при запуске программы данные загружаются из trainings.json
-✅ Обработка ошибок – если файл повреждён, программа показывает ошибку

## Примеры использования

### Пример 1: Добавление первой тренировки

**Действия:**
1. В поле «Дата» введите `2025-12-20`
2. Выберите «Тип тренировки» → `Бег`
3. В поле «Длительность» введите `45`
4. Нажмите кнопку **«➕ Добавить тренировку»**

### Пример 2: Фильтрация по типу тренировки

**Действия:**
1. В блоке «Фильтрация» выберите тип → `Плавание`
2. Нажмите **«🔍 Применить фильтр»**

### Пример 3: Фильтрация по дате

**Действия:**
1. В поле фильтра «Дата» введите `2025-12-20`
2. Нажмите **«🔍 Применить фильтр»**

### Пример 4: Комбинированная фильтрация (по типу И дате)

**Действия:**
1. Выберите тип `Бег`
2. В поле даты введите `2025-12-20`
3. Нажмите **«🔍 Применить фильтр»**
